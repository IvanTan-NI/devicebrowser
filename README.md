# Device Browser

Device Browser is a Windows Presentation Foundation (WPF) application for
browsing simulated devices and viewing their details.

## Requirements

- Windows
- .NET 10 SDK

## Run the application

From the repository root, run:

```powershell
dotnet run --project .\src\DeviceBrowser\DeviceBrowser.csproj
```

Alternatively, open the repository folder in Visual Studio, select
`DeviceBrowser` as the startup project, and run it.

## Use the application

1. Select a device from the list.
2. View the selected device's information in the details panel.
